Sableau — Deterministic
Browser Automation

An LLM explores a live legacy banking application once. Sableau compiles that run into a typed, versioned capability artifact that replays afterwards with zero model calls — same steps, new inputs, no planner in the loop. Seven production workflows ship this way, from sign-on and member lookup through transfers, share opening, and supervisor-only account holds.

Each capability is projected straight from its artifact into a FastAPI invoke endpoint, a natural-language chat front door, and a run dashboard that streams every step, timing, and screenshot. Runtime outcomes are typed rather than boolean: a nonexistent member is a business outcome, not a crash. High-risk steps require explicit confirmation, credentials are redacted from logs, evidence, and API echoes, and a permission-denied run pauses the browser session and escalates to a human, who takes control of that same Chromium session through the dashboard and hands it back with retry, continue, or abort.
