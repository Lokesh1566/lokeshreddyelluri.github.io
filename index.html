013.3M rows

022.3% quarantined

033 quality layers

System stage01 / 04

Input

NYC TLC trip records enter through a streaming ingestion boundary with the raw payload preserved.

Challenge

Schema drift and invalid records can silently corrupt downstream analysis when ingestion is optimized only for throughput.

Engineering decision

Use a medallion architecture with Great Expectations at the quality boundary and quarantine failures instead of dropping them.

Measured outcome

The pipeline processed 3.3M rows while surfacing the 2.3% that failed validation for inspection and recovery.
