An LLM explores a live banking interface once. Sableau compiles the successful run into a typed, versioned capability that replays with new inputs—and no planner in the loop.

Problem

Legacy workflows are costly for an LLM to rediscover on every run.

Decision

Separate probabilistic discovery from deterministic execution.

Safety

Typed outcomes, explicit confirmation, redaction, and human handoff.

Proof

Seven end-to-end capabilities replay with a tested zero-model-call path.
